# Sa meva vida ❤️

Pàgina web romàntica d'un sol arxiu (`index.html`), sense dependències (només Google Fonts).

Per canviar dades (noms, dates, llistes, llocs, cartes), edita es principi des `<script>` de `index.html`:
`CONFIG`, `LLISTES`, `LLOCS` i `CARTES`.

## Publicar-la amb GitHub Pages
1. Crea un repositori nou a github.com.
2. Puja `index.html`, `.nojekyll` i `README.md`.
3. Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / `(root)` > Save.
4. Al cap d'1-2 minuts sa pàgina serà a `https://EL-TEU-USUARI.github.io/NOM-DEL-REPO/`.
